Pizza Sales Analysis using SQL

 About the Project  
This project is based on a fictional pizza store’s sales data. I used SQL to analyze orders, identify best-selling pizzas, find peak sales times, and calculate revenue.📂 What’s in the Data?  
-**orders** – order ID, date, time  
- **order_details** – what pizzas were ordered and how many  
- **pizzas** – pizza size, price  
- **pizza_types** – pizza name, ingredients, category  

 What I Did  
- Found total revenue  
- Found top 5 best-selling pizzas  
- Analyzed when people order the most  
- Grouped sales by day, week, and month
